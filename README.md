What is LitecoinII?
-------------------

LitecoinII (LC2) is a peer-to-peer digital currency derived from the Litecoin codebase.

The goal of LitecoinII is to provide a clean, modern Scrypt-based blockchain built from the latest stable Litecoin Core release, while remaining fully open-source and community-driven.

Like Litecoin, LitecoinII enables fast and low-cost payments anywhere in the world without relying on a central authority. Transactions are verified by network nodes through cryptography and recorded on a distributed public ledger known as the blockchain.

This software allows anyone to run a full node, validate transactions, and participate in securing the LitecoinII network.

LitecoinII also explores the idea of giving a new generation of users and developers the opportunity to participate in a Scrypt-based blockchain from its early stages, similar to what early participants experienced with Litecoin.

Development Process
-------------------

The `master` branch tracks upstream Litecoin development and is kept synchronized with the Litecoin repository when possible.

The `0.21` branch contains the LitecoinII implementation derived from Litecoin Core v0.21.4.

Release tags are created periodically to mark stable versions of LitecoinII Core.
